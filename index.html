What it does

It replaces a physical whiteboard with a digital one that every computer keeps in sync automatically.

  • No internet required

    It only talks to other computers on the same office network. If the internet is out, this keeps working.

  • Nothing to set up

    Install it on a computer and it finds the others on its own. No addresses to type in, no accounts to create.

  • No single point of failure

    One computer keeps the master copy in the background. If that computer is turned off, another one takes over within seconds and nothing is lost.

  • Works on the computers you already have

    It's a single program file. No installer, no admin password, no other software to install first.

  • Old entries stand out

    After a set number of minutes, an entry changes color so it doesn't get forgotten on a busy day.

  • Updates itself

    When a newer version is available, each computer downloads it in the background and shows a banner to restart when ready. Nobody has to reinstall anything by hand.
